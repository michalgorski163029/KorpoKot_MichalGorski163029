Temat: KorpoKot – system zarządzania pracownikami fikcyjnej kociej korporacji. 

Opis: KorpoKot to humorystyczna aplikacja webowa służąca do zarządzania pracownikami fikcyjnej firmy, w której zatrudnione są koty. System umożliwia dodawanie, przeglądanie, edytowanie i usuwanie pracowników oraz przypisywanie im stanowisk i statusów aktywności. Użytkownik może przeglądać profile kotów, wyszukiwać pracowników i zarządzać przydzielonymi zadaniami. Aplikacja łączy funkcjonalność prostego systemu HR z humorystyczną tematyką. 

Rodzaj aplikacji: Webowa. 

Główne zasoby CRUD: Pracownik (kot) – imię, stanowisko, dział, wiek, status, poziom lenistwa. Dodatkowy zasób: zadanie – tytuł, opis, status, przypisany pracownik. 

Frameworki: 

Next.js (A) – budowa aplikacji, nawigacji i API REST. 

Bootstrap (B) – budowa responsywnego interfejsu z gotowych komponentów. 

Playwright (C) – automatyczne testowanie dodawania, edytowania i usuwania pracowników oraz walidacji formularzy. 

Baza danych: SQLite.
